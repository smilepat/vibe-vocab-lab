# 결정 문서 — 1Hour Vocab (모바일 우선)

코드보다 먼저 정한다. 여기 적은 값은 스토어에 올린 뒤 바꾸기 어렵다.

## ① 바꿀 수 없는 값
- 앱 이름: 1Hour Vocab
- 앱 ID: iOS `com.example.vocab1h` / Android `com.example.vocab1h` (실제 출시 때 학교·본인 도메인으로)
- 딥링크 주소: `vocab1h://`
- 서명 키: EAS가 보관 (분실 시 같은 앱으로 업데이트 불가)

## ② 데이터
- 기기 안 SQLite가 기본 저장소. 학습 기록마다 `id`, `updatedAt`, `deviceId`
- 단어 데이터는 앱에 포함 (첫 버전 50개 이하)
- 서버 동기화는 2판에서. 지금 구조로 나중에 붙일 수 있게만 둔다

## ③ 구조
- 화면(App.tsx) → 학습 엔진(src/engine, 순수 TypeScript) → 기기 기능 연결부(src/platform)
- 학습 엔진은 휴대폰 없이 `node --test`로 시험한다

## ④ 권한
- 알림: [복습 알림 받기]를 누를 때 앱 안에서 이유를 먼저 설명하고 묻는다. 거부해도 앱은 동작
- 마이크: 1판에서는 쓰지 않는다

## ⑤ 개인정보·아동
- 1판은 로그인 없음, 기기에만 저장, 수집하는 개인정보 없음
- 만 14세 미만 대상이므로 로그인을 붙일 때는 법정대리인 동의 절차를 먼저 설계한다

## ⑥ 업데이트
- 화면·로직 변경: EAS Update (심사 없이)
- 기기 기능·권한 변경: 스토어 심사
