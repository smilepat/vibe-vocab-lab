1Hour Vocab 실습실

바이브코딩으로 영어 단어 카드 앱을 만들어 봅니다. 원하는 앱을 말로 설명하면 AI(Claude 또는 Gemini)가 코드를 쓰고, 오른쪽 미리보기에 바로 나타납니다. 네 단계를 마치면 휴대폰에 설치할 앱 파일을 내려받습니다. 수업에서 VS Code의 Claude Code로 하는 일을 이 화면에서 똑같이 연습합니다.

API 키 없이 Claude가 코드를 쓰는 모습 보기

같은 실습실을 claude.ai에도 올려 두었습니다. 거기서 열면 키를 넣지 않아도 보는 사람의 Claude 계정으로 Claude가 코드를 씁니다. 수업 시작 때 데모로 보여 주기 좋습니다.

claude.ai 로그인이 필요하고, 처음 보낼 때 Claude 사용을 허락하는 창이 뜹니다. 사용량은 보는 사람의 Claude 계정에서 나갑니다. Gemini 키와 API 키 설정은 이 화면에만 있습니다.
