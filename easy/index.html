앱 만들기

12분
이렇게 하기
  1. 위쪽에서 1 앱 만들기가 켜져 있는지 봅니다.
  2. 프롬프트 칸에 글이 이미 들어 있습니다. 고치지 않아도 됩니다.
  3. 보내기를 누르고 30초~1분 기다립니다.
  4. 오른쪽 미리보기에서 카드를 눌러 봅니다.
안 되면 프롬프트 칸에 이렇게 쓰기카드를 눌러도 뜻이 안 보여.
실습실 1단계 열기 →
이렇게 말하기
영어 단어 카드 앱을 만들어 줘. - 파일은 index.html, style.css, app.js 세 개로 나눠 줘. - 화면 가운데에 카드가 하나 있어. 앞면에는 영어 단어가 보이고, 카드를 누르면 뒤집혀서 한국어 뜻이 보여. - 카드 아래에 [이전] [외웠어요] [다음] 버튼을 둬 줘. [외웠어요]를 누르면 그 단어를 외운 단어로 표시하고 다음 카드로 넘어가. - 진도 막대와 "외운 단어 수 / 전체 단어 수"를 보여 줘. - 외운 기록은 localStorage에 저장해서 새로고침해도 남게 해 줘. - 단어는 abandon(버리다), ability(능력), abroad(해외로), absence(부재), accept(받아들이다) 5개로 시작해 줘. - 휴대폰 화면을 먼저 생각해서 만들어 줘. 화면 폭이 860px 이상이면 오른쪽에 전체 단어 목록을 보여 주고, 목록에서 단어를 누르면 그 카드로 이동하게 해 줘. - 휴대폰, 태블릿, 컴퓨터가 모두 같은 파일 하나로 동작해야 해. - 서버나 외부 라이브러리 없이 HTML, CSS, JavaScript만 써 줘. 파일마다 전체 코드를 따로 보여 줘.
파일로 저장하기
  1. AI가 보여 준 코드마다 복사를 눌러 메모장에 붙여 넣습니다.
  2. 파일 → 다른 이름으로 저장. 파일 형식은 모든 파일, 인코딩은 UTF-8, 이름은 index.html. style.css, app.js도 똑같이 저장합니다.
  3. vocab-app 폴더에서 index.html을 더블클릭합니다.
안 되면파일 이름이 index.html.txt로 저장됐으면 파일 형식을 모든 파일로 바꿔 다시 저장합니다. 화면이 이상하면 AI에게 "index.html을 열었는데 카드가 안 보여. 고친 파일의 전체 코드를 다시 보여 줘."라고 말합니다.

실습실 3단계 열기 →
이렇게 말하기
이 앱을 휴대폰 홈 화면에 설치할 수 있는 PWA로 만들어 줘. - manifest.json을 만들어 줘. 앱 이름은 "1Hour Vocab", start_url과 scope는 "./", display는 standalone, 아이콘은 icon-192.png와 icon-512.png를 써. - sw.js(서비스 워커)를 만들어 줘. 앱 파일과 아이콘을 저장해 두고, 인터넷이 끊기면 저장해 둔 파일로 열리게 해 줘. - 모든 경로는 "./"로 시작하는 상대경로로 써 줘. GitHub Pages의 하위 주소에서 동작해야 해. - index.html에 manifest 연결, apple-touch-icon 연결, 서비스 워커 등록 코드를 추가해 줘. - 끝나면 오프라인에서 되는 것과 안 되는 것을 짧게 정리해 줘. 새로 만든 파일과 바뀐 파일의 전체 코드를 보여 줘.
zip으로 받기
지금까지 만든 파일을 모두 모으고, 아이콘 icon-192.png와 icon-512.png도 만들어서 zip 파일 하나로 줘.

zip을 받으면 압축을 풀어 파일 7개를 vocab-app 폴더에 넣습니다.

zip을 못 주는 AI라면manifest.json과 sw.js를 1단계처럼 저장하고, 정사각형 그림 두 장을 icon-192.png(192×192), icon-512.png(512×512) 이름으로 폴더에 넣습니다.

휴대폰 설치와 인터넷 없이 열기는 내 컴퓨터에서는 시험할 수 없습니다. 4단계에서 올린 뒤 확인합니다.

인터넷에 올리고 휴대폰에 설치

18분
① 앱 파일 받기

3단계에서 모은 vocab-app 폴더의 파일 7개를 그대로 씁니다.

  1. 실습실 4 내려받아 배포에서 앱 파일 내려받기를 누릅니다.
  2. 받은 zip의 압축을 풉니다. 파일 7개가 나옵니다.
② 어디에 올릴지 하나 고르기
  1. github.com에서 + → New repository. 이름은 vocab-app, Public을 고르고 만듭니다.
  2. uploading an existing file을 눌러 파일 7개를 끌어다 놓고 Commit changes. 폴더째 올리지 않습니다.
  3. Settings → Pages에서 main과 / (root)를 고르고 Save.
  4. 1~3분 뒤 https://내아이디.github.io/vocab-app/ 을 엽니다.
404가 나오면1~3분 더 기다린 뒤 새로고침합니다. 그래도 안 되면 파일 7개가 폴더 안이 아니라 맨 위에 있는지 봅니다.
  1. app.netlify.com에 로그인합니다. GitHub 계정으로 로그인해도 됩니다.
  2. app.netlify.com/drop 을 엽니다.
  3. 압축을 푼 폴더를 통째로 끌어다 놓습니다.
  4. 몇 초 뒤 나오는 https://이름.netlify.app 주소를 엽니다.
주의로그인하지 않고 올리면 사이트가 잠시 뒤 지워질 수 있습니다. 꼭 로그인한 뒤 올립니다. 폴더 안에 폴더가 또 있으면 index.html이 들어 있는 폴더를 끌어다 놓습니다.
  1. GitHub Pages의 1~2번처럼 GitHub 저장소 vocab-app을 만들고 파일 7개를 올립니다.
  2. vercel.com에 GitHub 계정으로 로그인합니다.
  3. Add New… → Project에서 vocab-app 옆의 Import를 누르고, 설정은 그대로 두고 Deploy.
  4. 끝나면 나오는 짧은 주소 https://vocab-app.vercel.app 을 엽니다.
주의긴 주소(중간에 영어·숫자가 섞인 주소)는 다른 사람이 열 때 로그인을 요구할 수 있습니다. 친구에게는 짧은 주소를 보냅니다.
③ 휴대폰에 설치
  1. 휴대폰의 Chrome이나 Safari로 내 주소를 엽니다. 카카오톡 안에서 열면 설치가 안 됩니다.
  2. 홈 화면에 설치하고, 비행기 모드에서도 열어 봅니다.
