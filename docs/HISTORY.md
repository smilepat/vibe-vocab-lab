### 저장소로 옮기며 바뀐 것
| 바뀐 것 | 이유 |
|---|---|
| `ai.js`에 자기 API 키 공급자 추가 (브라우저에서 Messages API 직접 호출, `anthropic-dangerous-direct-browser-access`) | claude.ai 밖에는 보는 사람의 Claude 계정이 없음 |

### 저장소 시험 (2026-10-04, `npm test`, 59개 전부 통과)

## 2026-10-04 (밤) 기술 용어 풀이
