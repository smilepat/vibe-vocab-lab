만들기: 말로 설명해서 단어 카드 앱 만들기

목표: 컴퓨터 브라우저에서 카드를 넘기고, 외운 기록이 새로고침 후에도 남는다.

프롬프트 1 · 앱 만들기
영어 단어 카드 앱을 만들어 줘.

- 파일은 index.html, style.css, app.js 세 개로 나눠 줘.
- 화면 가운데에 카드가 하나 있어. 앞면에는 영어 단어가 보이고, 카드를 누르면 뒤집혀서 한국어 뜻이 보여.
- 카드 아래에 [이전] [외웠어요] [다음] 버튼을 둬 줘. [외웠어요]를 누르면 그 단어를 외운 단어로 표시하고 다음 카드로 넘어가.
- 진도 막대와 "외운 단어 수 / 전체 단어 수"를 보여 줘.
- 외운 기록은 localStorage에 저장해서 새로고침해도 남게 해 줘.
- 단어는 abandon(버리다), ability(능력), abroad(해외로), absence(부재), accept(받아들이다) 5개로 시작해 줘.
- 휴대폰 화면을 먼저 생각해서 만들어 줘. 화면 폭이 860px 이상이면 오른쪽에 전체 단어 목록을 보여 주고, 목록에서 단어를 누르면 그 카드로 이동하게 해 줘.
- 휴대폰, 태블릿, 컴퓨터가 모두 같은 파일 하나로 동작해야 해. 기기별로 따로 만들지 마.
- 서버나 외부 라이브러리 없이 HTML, CSS, JavaScript만 써 줘.
  1. Claude가 파일 3개를 만들면 VS Code 왼쪽에 index.html, style.css, app.js 가 보입니다.
  2. 파일 탐색기에서 index.html 을 더블클릭해 브라우저로 엽니다.
  3. 카드 누르기, 버튼 3개, 새로고침을 차례로 해 봅니다.
  4. 브라우저 창을 좁혔다 넓혀 봅니다. 넓으면 단어 목록이 나오고, 좁으면 사라져야 합니다. F12 → 휴대폰 모양 아이콘을 누르면 휴대폰 화면으로도 볼 수 있습니다.
  5. 이상한 곳이 있으면 본 그대로 말합니다. 예: "외웠어요를 눌렀는데 진도 막대가 안 움직여. 고쳐 줘."
확인 지점 ②
  • 카드를 누르면 뜻이 보인다
  • 이전·다음 버튼으로 5개 단어를 오간다
  • 외웠어요를 누르면 진도가 오른다
  • 새로고침해도 진도가 그대로다
  • 창을 넓히면 단어 목록이 나오고, 가로 스크롤이 생기지 않는다
강사 메모

Claude가 일하는 동안 화면을 보세요. 어떤 파일을 만드는지 말해 주고 있어요. 다 되면 바로 열어서 직접 눌러 보는 게 바이브코딩의 절반입니다.

AI가 만든 결과는 학생마다 조금씩 다릅니다. 확인 지점 네 가지만 되면 모양이 달라도 통과입니다.

22분이 됐는데도 확인 지점을 못 넘긴 학생은 정답 키트의 index.html, style.css, app.js 를 폴더에 넣고 다음 단계로 함께 갑니다. 늦은 학생을 기다리면 배포 시간이 사라집니다.

브라우저 화면이 비어 있으면 F12 → Console의 빨간 글자를 복사해 Claude에게 "이 오류를 고쳐 줘"라고 보내게 합니다. 이것도 오늘 배울 습관입니다.

PWA로: 설치할 수 있는 앱으로 바꾸기

PWAProgressive Web App(프로그레시브 웹 앱)의 줄임말. HTML·CSS·JavaScript로 만든 웹사이트에 앱 정보 파일(manifest)과 서비스 워커(sw.js)를 더한 것으로, 휴대폰·컴퓨터 홈 화면에 앱처럼 설치되고 인터넷이 끊겨도 열립니다. 앱 스토어를 거치지 않고 웹 주소로 배포합니다.

목표: 폴더에 파일 7개가 모두 있다.

  1. 강사가 나눠 준 icon-192.png, icon-512.png 를 vocab-app 폴더에 넣습니다.
  2. 아래 프롬프트를 보냅니다.
프롬프트 3 · PWA로 바꾸기
이 앱을 휴대폰 홈 화면에 설치할 수 있는 PWA로 만들어 줘.

- manifest.json을 만들어 줘. 앱 이름은 "1Hour Vocab", start_url과 scope는 "./", display는 standalone, 아이콘은 이 폴더의 icon-192.png와 icon-512.png를 써.
- sw.js(서비스 워커)를 만들어 줘. 앱 파일과 아이콘을 저장해 두고, 인터넷이 끊기면 저장해 둔 파일로 열리게 해 줘.
- 모든 경로는 "./"로 시작하는 상대경로로 써 줘. GitHub Pages의 하위 주소에서 동작해야 해.
- index.html에 manifest 연결, apple-touch-icon 연결, 서비스 워커 등록 코드를 추가해 줘.
- 아이콘 파일이 폴더에 없으면 만들지 말고 나에게 알려 줘.
- 끝나면 오프라인에서 되는 것과 안 되는 것을 표로 정리해 줘. 브라우저마다 설치 방법과 오프라인 동작이 다를 수 있으니 Chrome, Safari, Firefox를 나눠서 알려 줘.
index.html화면 구성
style.css모양
app.js버튼 동작과 저장
manifest.json앱 이름·아이콘·시작 주소
sw.js파일 저장, 오프라인 열기
icon-192.png홈 화면 아이콘
icon-512.png큰 아이콘
확인 지점 ④
  • VS Code 왼쪽에 위 7개 파일이 모두 보인다
강사 메모

manifest.json은 휴대폰에게 "이 앱 이름은 이것, 아이콘은 이것, 열면 여기서 시작"이라고 알려 주는 파일입니다. sw.js는 앱 파일을 휴대폰에 저장해 두었다가 인터넷이 끊기면 저장본을 보여 줍니다.

서비스 워커는 https 주소에서만 동작합니다. 그래서 파일을 더블클릭해서 연 화면에서는 오프라인 기능을 확인할 수 없고, 다음 단계에서 배포한 뒤에 확인합니다. 학생이 "PWA가 안 돼요"라고 하면 대부분 이 경우입니다.

원본 계획처럼 저장소 이름을 경로에 적으면(/1hour-vocab-pwa/) 저장소 이름이 다른 학생의 앱은 오프라인이 깨집니다. 프롬프트에 상대경로를 명시한 이유입니다.

배포: GitHub Pages로 인터넷 주소 받기

목표: https://아이디.github.io/vocab-app/ 주소에서 앱이 열린다.

입문 수업에서는 git 명령 없이 웹에서 파일을 끌어다 올리는 방법을 기본으로 합니다. git 로그인 문제로 10분이 사라지는 일을 막기 위해서입니다.

  1. github.com 오른쪽 위 + → New repository
  2. Repository name에 vocab-app, Public 선택 → Create repository
  3. 새 화면에서 uploading an existing file 링크를 누릅니다.
  4. 폴더 안의 파일 7개를 선택해서 끌어다 놓습니다. 폴더째 올리면 주소가 하나 더 깊어져 앱이 안 열립니다.
  5. 아래 Commit changes
  6. Settings → Pages → Source는 Deploy from a branch, Branch는 main / / (root) → Save
  7. 1~3분 기다린 뒤 Pages 화면 위쪽에 나온 주소를 엽니다.
확인 지점 ⑤
  • 내 주소에서 카드 앱이 열린다
  • 저장소 첫 화면에 index.html 이 폴더 없이 바로 보인다
심화 트랙 · git을 이미 쓰는 학생
이 폴더를 git 저장소로 만들고 첫 커밋을 해 줘. 그다음 gh 명령으로 내 GitHub 계정에 vocab-app이라는 public 저장소를 만들어서 push하고, GitHub Pages를 main 브랜치 루트로 켜 줘. 끝나면 Pages 주소를 알려 줘.
강사 메모

// 기본 단어 목록 — 이 부분만 바꾸면 나만의 단어장이 됩니다
const defaultWords = [
    { word: 'abandon', meaning: '버리다, 포기하다' },
    { word: 'ability', meaning: '능력' },
    { word: 'abroad', meaning: '해외로' },
    { word: 'absence', meaning: '부재, 결석' },
    { word: 'accept', meaning: '받아들이다' }
];

const STORAGE_KEY = 'vocab-learned';

let learned = {};      // { abandon: true, ... } 외운 단어 기록
let currentIndex = 0;

const card = document.getElementById('card');

// 저장된 기록 불러오기
function loadProgress() {
    try {
        learned = JSON.parse(localStorage.getItem(STORAGE_KEY)) || {};
    } catch (e) {
        learned = {};
    }
}

// 기록 저장하기
function saveProgress() {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(learned));
}

// 지금 카드 보여주기
function renderCard() {
    const item = defaultWords[currentIndex];
    card.classList.remove('flipped');
    card.classList.toggle('learned', !!learned[item.word]);
    document.getElementById('card-front').textContent = item.word;
    document.getElementById('card-back').textContent = item.meaning;
    updateProgress();
    renderList();
}

// 넓은 화면용 단어 목록 (누르면 그 카드로 이동)
function renderList() {
    const list = document.getElementById('word-list');
    list.innerHTML = '';
    defaultWords.forEach((w, i) => {
        const li = document.createElement('li');
        const btn = document.createElement('button');
        btn.type = 'button';
        btn.className = i === currentIndex ? 'current' : '';
        btn.textContent = w.word;
        const mark = document.createElement('span');
        mark.className = 'mark';
        mark.textContent = learned[w.word] ? '✓' : '';
        btn.appendChild(mark);
        btn.addEventListener('click', () => {
            currentIndex = i;
            renderCard();
        });
        li.appendChild(btn);
        list.appendChild(li);
    });
}

// 진도 막대 업데이트
function updateProgress() {
    const total = defaultWords.length;
    const done = defaultWords.filter(w => learned[w.word]).length;
    document.getElementById('progress-fill').style.width = (done / total) * 100 + '%';
    document.getElementById('progress-text').textContent = `${done} / ${total} 어휘 학습함`;
    document.getElementById('subtitle').textContent = `영어 어휘 학습 - ${done}/${total} 완료`;
}

function goNext() {
    currentIndex = (currentIndex + 1) % defaultWords.length;
    renderCard();
}

// 카드 뒤집기 (클릭 또는 키보드)
card.addEventListener('click', () => card.classList.toggle('flipped'));
card.addEventListener('keydown', (e) => {
    if (e.key === 'Enter' || e.key === ' ') {
        e.preventDefault();
        card.classList.toggle('flipped');
    }
});

document.getElementById('prev-btn').addEventListener('click', () => {
    currentIndex = (currentIndex - 1 + defaultWords.length) % defaultWords.length;
    renderCard();
});

document.getElementById('next-btn').addEventListener('click', goNext);

// 외웠어요: 표시를 켜고 끈 뒤 다음 카드로
document.getElementById('mark-btn').addEventListener('click', () => {
    const w = defaultWords[currentIndex].word;
    learned[w] = !learned[w];
    saveProgress();
    goNext();
});

// 발음 듣기 (브라우저 내장 음성)
document.getElementById('speak-btn').addEventListener('click', () => {
    if (!('speechSynthesis' in window)) return;
    const utter = new SpeechSynthesisUtterance(defaultWords[currentIndex].word);
    utter.lang = 'en-US';
    speechSynthesis.cancel();
    speechSynthesis.speak(utter);
});

// 처음부터: 두 번 눌러야 지워짐 (실수 방지)
const resetBtn = document.getElementById('reset-btn');
let resetArmed = false;
resetBtn.addEventListener('click', () => {
    if (!resetArmed) {
        resetArmed = true;
        resetBtn.textContent = '한 번 더 누르면 지워져요';
        setTimeout(() => {
            resetArmed = false;
            resetBtn.textContent = '처음부터';
        }, 3000);
        return;
    }
    learned = {};
    saveProgress();
    currentIndex = 0;
    resetArmed = false;
    resetBtn.textContent = '처음부터';
    renderCard();
});

loadProgress();
renderCard();

// 앱을 고칠 때마다 숫자를 올려 주세요 (v1 → v2)
const CACHE_NAME = 'vocab-v1';

// 상대경로라서 저장소 이름이 무엇이든 동작합니다
const FILES = [
  './',
  './index.html',
  './style.css',
  './app.js',
  './manifest.json',
  './icon-192.png',
  './icon-512.png'
];

// 설치: 앱 파일을 미리 저장
self.addEventListener('install', event => {
  event.waitUntil(caches.open(CACHE_NAME).then(cache => cache.addAll(FILES)));
  self.skipWaiting();
});

// 활성화: 옛 버전 저장본 정리
self.addEventListener('activate', event => {
  event.waitUntil(
    caches.keys().then(keys =>
      Promise.all(keys.filter(k => k !== CACHE_NAME).map(k => caches.delete(k)))
    ).then(() => self.clients.claim())
  );
});

// 요청: 인터넷이 되면 새로 받고, 끊기면 저장본 사용
self.addEventListener('fetch', event => {
  if (event.request.method !== 'GET') return;
  event.respondWith(
    fetch(event.request)
      .then(response => {
        const copy = response.clone();
        caches.open(CACHE_NAME).then(cache => cache.put(event.request, copy));
        return response;
      })
      .catch(() => caches.match(event.request, { ignoreSearch: true }))
  );
});
