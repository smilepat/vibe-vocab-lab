인터넷에 올리고 휴대폰에 설치

18분
이렇게 하기
  1. 실습실 4 내려받아 배포에서 앱 파일 내려받기를 누르고, zip 압축을 풉니다.
  2. github.com에서 + → New repository. 이름은 vocab-app, Public을 고르고 만듭니다.
  3. uploading an existing file을 눌러 파일 7개를 끌어다 놓고 Commit changes를 누릅니다. 폴더째 올리지 않습니다.
  4. Settings → Pages에서 main과 / (root)를 고르고 Save.
  5. 1~3분 기다린 뒤 내 주소를 엽니다.
  6. 휴대폰에서 주소를 열고 홈 화면에 설치합니다. 비행기 모드에서도 열어 봅니다.
주소를 열었는데 404가 나오면1~3분 더 기다린 뒤 새로고침합니다. 그래도 안 되면 파일 7개가 폴더 안이 아니라 맨 위에 있는지 봅니다.

막혔을 때

"요청이 많습니다"가 나올 때

사람들이 한꺼번에 보내서 그렇습니다. API 키 설정에서 모델을 Flash-Lite로 바꾸고 다시 보냅니다.

아무리 해도 안 될 때

예시 결과 적용을 누르면 그 단계의 정답 결과가 들어가고 다음 단계로 갈 수 있습니다.

그림은 예시입니다. 단어나 색이 조금 달라도, 그림처럼 움직이면 성공입니다. 자세한 설명은 강의 지도안 학생용에 있습니다. 체크 표시는 이 브라우저에만 저장됩니다.
