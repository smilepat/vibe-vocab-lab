수업 전 점검

사이트의 자동 시험은 모두 통과했지만, 두 가지는 사람이 직접 해 봐야 압니다. A. 진짜 API 키로 AI 부르기와 B. 실제 휴대폰에 설치하기입니다. 단계를 따라 하며 결과를 표시하고, 끝에서 결과를 복사해 Claude에게 보내 주면 문제가 있는 곳을 바로 고칩니다.

A. API 키 0 / 0 B. 휴대폰 0 / 0
점검 A · 약 10분

진짜 API 키로 실습실 1~3단계

준비물 Claude 또는 Gemini API 키, 컴퓨터의 Chrome·Edge 비용 Claude Opus 5.5 기준 한 번 보낼 때 대략 0.1~0.3달러, 세 단계 합쳐 1달러 안쪽 (Sonnet은 약 절반)

키는 이 대화나 다른 곳에 붙여 넣지 말고, 실습실의 키 설정 칸에만 직접 넣으세요. 내 노트북에서만 쓰는 키라면 지우지 않아도 됩니다(학생 기기에는 전달되지 않음). 다만 화면을 공유하는 동안 Network 요청의 Headers와 Application 저장 공간은 열지 마세요 — 키가 그대로 보입니다. 학생에게 나눠 줄 키는 수업용으로 따로 만들어 사용 한도를 걸고, 수업이 끝나면 AI Studio에서 삭제합니다.

  1. 키 만들기

    Claude: console.anthropic.com → API Keys (sk-ant-로 시작) · Gemini: Google AI Studio → Get API key (보통 AIza로 시작)

  2. 실습실을 새 창으로 열고 처음 상태로

    아래 버튼으로 연 뒤, 대화 기록 옆 처음부터 다시를 두 번 누릅니다 (키 설정은 지워지지 않습니다).
    실습실 1단계 열기 ↗

  3. 키 넣기

    API 키 설정 → 서비스(Claude 또는 Gemini) → 키 붙여 넣기 → 이 기기에 기억은 끈 채로 → 저장.
    • 오른쪽 위가 "Claude 연결됨 (내 API 키)" 또는 "Gemini 연결됨"으로 바뀌고 보내기 버튼이 보이면 성공

  4. 요청 기록 창 열기

    F12 → 위쪽 Network 탭 → 필터 버튼 Fetch/XHR. Filter 칸에 messages(Claude) 또는 generateContent(Gemini)를 적어 두면 AI 요청만 보입니다.
    • Network는 F12를 연 뒤의 요청만 기록합니다. 이름 앞에 ⚙가 있고 Initiator가 sw.js인 줄(실습실·manifest 등)은 오프라인 저장본을 새로 받는 기록이라 AI 요청이 아닙니다

  5. 1단계 보내기

    기본 프롬프트 그대로 보내기. 30초~2분 기다립니다.

  6. Network에서 요청 횟수 보기

    방금 보낸 요청이 몇 줄 생겼는지 봅니다. Type이 preflight인 줄은 세지 않습니다 (브라우저가 "보내도 되나" 먼저 묻는 확인 요청이라 요청마다 하나씩 붙습니다). Type이 fetch인 줄만 셉니다.
    • fetch 1줄, 상태 200: 추가 설정(JSON 모양 고정 등)까지 그대로 받아들여짐 — 가장 좋음
    • fetch 2줄, 400 다음 200: 추가 설정을 거절해 기본 요청으로 다시 보냄 — 정상 동작. 400 줄을 눌러 Response의 message를 아래 메모에 적어 주세요

  7. 2단계, 3단계도 보내기

    2단계에서 발음 듣기 칩 → 보내기. 3단계에서 기본 프롬프트 → 보내기.

  8. 키 지우기

    API 키 설정 → 키 지우기. 오른쪽 위가 "예시 모드"로 돌아오면 끝. 나만 쓰는 노트북이고 계속 시연에 쓸 키라면 건너뜀으로 표시해도 됩니다.
점검 B · 기기마다 약 5분

실제 휴대폰에 설치하고 비행기 모드로

준비물 Android(Chrome) 또는 iPhone(Safari), 와이파이 기기

QR을 카카오톡으로 보내거나 카톡 안에서 열면 설치가 안 됩니다. 휴대폰 카메라 앱으로 찍고, Chrome(Android)이나 Safari(iPhone)로 엽니다.

정답 키트 앱
실습실

  1. 정답 키트 앱 열기

    정답 키트 앱 QR을 카메라로 찍어 엽니다. 카드를 눌러 뒤집고, 외웠어요를 한 번 누릅니다.

  2. 홈 화면에 설치

    Android: Chrome 메뉴 ⋮ → 앱 설치 (없으면 홈 화면에 추가) · iPhone: Safari 공유 버튼 → 홈 화면에 추가

  3. 비행기 모드로 열기

    앱을 완전히 닫고(최근 앱 목록에서 밀어 닫기) → 비행기 모드 켜기 → 홈 화면 아이콘으로 다시 엽니다.

  4. 실습실도 설치해 보기 (선택)

    실습실 QR로 열어 같은 방법으로 설치하고, 비행기 모드에서 열어 예시 결과 적용이 되는지 봅니다. 휴대폰에서는 결과가 나오면 미리보기로 자동으로 내려가야 합니다.

  5. 비행기 모드 끄기

    점검이 끝나면 비행기 모드를 끕니다.
