먼저 정할 것: 정말 스토어 앱이 필요한가

PWA로 홈 화면에 설치하는 것만으로 수업과 개인 학습에는 충분합니다. 아래 경우에만 포장을 고려하세요.

PWA — Progressive Web App(프로그레시브 웹 앱)의 줄임말. HTML·CSS·JavaScript로 만든 웹사이트에 앱 정보 파일(manifest)과 서비스 워커(sw.js)를 더한 것으로, 휴대폰·컴퓨터 홈 화면에 앱처럼 설치되고 인터넷이 끊겨도 열립니다. 앱 스토어를 거치지 않고 웹 주소로 배포합니다.

  • Google Play나 App Store에서 검색되게 하고 싶다
  • 학교 기기 관리(MDM)로 앱을 배포해야 한다
  • iPhone에서 푸시 알림·안정적인 저장 공간 같은 네이티브 기능이 꼭 필요하다

따라 하기

1

새 폴더를 만들고 앱 파일을 www에 넣기

정답 키트 7개 파일(또는 실습실에서 내려받은 vocab-app.zip을 푼 파일)을 www 폴더에 넣습니다. 수업용 GitHub 저장소와는 다른 폴더에서 작업하세요.

터미널
mkdir vocab-native
cd vocab-native
npm init -y
mkdir www
# www 안에 index.html, style.css, app.js, manifest.json, sw.js, icon-192.png, icon-512.png 복사
2

Capacitor 설치

터미널
npm i @capacitor/core
npm i -D @capacitor/cli
3

앱 이름과 앱 ID 정하기

앱 ID는 전 세계에서 하나뿐이어야 합니다. com.example 부분을 학교나 본인 도메인을 거꾸로 쓴 것으로 바꾸세요. 스토어에 올린 뒤에는 바꿀 수 없습니다.

터미널
npx cap init "1Hour Vocab" com.example.vocab --web-dir www
4

Android·iOS 프로젝트 만들기

iOS는 Mac에서만 합니다. Windows라면 android 줄만 실행하세요.

터미널
npm i @capacitor/android @capacitor/ios
npx cap add android
npx cap add ios
5

앱 파일 옮겨 넣기

www의 파일을 Android·iOS 프로젝트로 복사합니다. www를 고칠 때마다 다시 실행합니다.

터미널
npx cap sync
6

기기에서 실행하기

휴대폰을 USB로 연결하거나 에뮬레이터를 켠 뒤 실행합니다. open은 Android Studio·Xcode를 열고, run은 바로 기기에 설치합니다.

Android
npx cap open android
npx cap run android
iOS (Mac)
npx cap open ios
npx cap run ios

막히면 npx cap doctor로 설치 상태를 확인하세요.

앱으로 포장하면 손볼 곳

카드 화면은 그대로 동작합니다. 아래 기능만 확인하세요.

기능웹(PWA)에서앱에서 생기는 일필요한 것
외운 기록 저장localStorage저장 공간이 부족하면 OS가 지울 수 있음@capacitor/preferences
발음 듣기Web Speech APIAndroid 웹뷰에서 동작이 일정하지 않음@capacitor-community/text-to-speech
오프라인sw.js파일이 앱 안에 들어가므로 필요 없음없음 (그대로 두어도 무방)
푸시 알림Web Push방식이 다름@capacitor/push-notifications + FCM(Android)·APNs(iOS)
설치 안내 문구브라우저별 안내이미 설치된 앱이므로 숨김Capacitor.isNativePlatform() 판별을 한 파일에만
플랫폼별 코드는 한 곳에만

"앱이면 이렇게, 웹이면 저렇게" 하는 분기는 platform.js 같은 파일 하나에 모으세요. 나머지 코드는 웹과 앱이 똑같이 쓰도록 두어야 한 번 고친 것이 양쪽에 반영됩니다.

프롬프트
이 폴더의 www에 있는 단어 카드 웹앱을 Capacitor 8로 Android 앱 프로젝트로 만들어 줘.
- 앱 이름은 "1Hour Vocab", 앱 ID는 com.example.vocab, webDir은 www.
- www 안의 코드는 고치지 마.
- 끝나면 npx cap doctor 결과와, 내 휴대폰에서 실행하려면 무엇을 해야 하는지 알려 줘.

스토어에 올리기 전 확인

  • 앱 아이콘과 시작 화면을 기기 크기별로 준비했다
  • 개인정보처리방침 주소가 있다 (외운 기록을 기기에만 저장한다는 내용이라도 필요)
  • 스토어용 스크린샷을 휴대폰·태블릿 크기로 찍었다
  • 앱 서명 키를 안전한 곳에 백업했다 (잃어버리면 같은 앱으로 업데이트할 수 없음)
  • 앱 ID와 버전 번호를 확인했다
