만들기

수업 60분 · 실습실 4단계
1

앱 만들기

카드·버튼·진도·저장이 들어간 단어 카드 앱을 말로 설명해서 만들고, 미리보기에서 눌러 확인합니다.

12분결과: 파일 3개실습실 1단계지도안
2

내 앱으로

내 단어·발음 듣기·색 중 하나만 골라 고칩니다. 한 번에 하나씩, 고칠 때마다 확인.

8분결과: 나만의 단어장실습실 2단계지도안
3

PWA로

manifest.json과 sw.js를 더해 홈 화면에 설치되고 인터넷이 끊겨도 열리게 합니다. 이렇게 만든 앱을 PWA라고 합니다.

6분결과: 파일 7개실습실 3단계지도안
4

배포하고 휴대폰에 설치

zip을 받아 GitHub Pages에 올리고, 휴대폰 홈 화면에 설치한 뒤 비행기 모드로 확인합니다. 완성본과 비교해 보세요.

18분결과: 내 앱 주소실습실 4단계지도안완성본
다음 목표는?

수업이 끝나면 앱을 어디까지 키울지 고릅니다. 스토어 앱이 꼭 필요한지가 기준입니다.

갈래 1
PWA로 충분수업·개인 학습용. 스토어 없이 주소로 나눠 줌
P1

기능 더하기

단어 추가 화면, a·b·c 퀴즈를 한 번에 하나씩.

다음 단계 프롬프트
P2

고친 것 다시 배포

GitHub에 파일을 다시 올리고, sw.js의 캐시 이름(v1→v2)을 올려 휴대폰에도 새 버전이 가게 합니다.

막혔을 때
갈래 2
웹도 쓰고 스토어에도지금 만든 앱을 그대로 감싸 Android·iOS 앱으로
W1

포장 과정 먼저 보기

설치 없이 8단계를 실제 출력으로 봅니다. 단계마다 Claude Code로 하는 법도 함께.

앱 포장 데모
W2

Capacitor로 포장

www에 앱 파일 → 설치 → 앱 이름·ID → Android·iOS 프로젝트 → 동기화.

앱 포장 지침
W3

휴대폰에서 실행

Android Studio(또는 Mac의 Xcode)를 설치하고 USB로 연결해 실행합니다.

데모 8단계
갈래 3
처음부터 휴대폰 앱알림·녹음·대용량 오프라인이 핵심일 때
M1

결정 문서 1장

앱 ID·저장·권한·개인정보(만 14세 미만)·업데이트를 코드보다 먼저.

모바일 우선 1단계
M2

프로젝트·앱 ID·기기 기능

Expo 프로젝트를 만들고 바꿀 수 없는 값을 고정, 필요한 기기 기능만 설치.

2~4단계
M3

학습 엔진·저장소·화면

휴대폰 없이 시험하는 엔진 → 기기 저장소 연결 → 화면 → 웹 미리보기로 눌러 보기.

5~7단계
M4

점검·스토어 테스트

빈 앱이라도 TestFlight·Play 내부 테스트까지 한 번 올려 봅니다.

8~9단계
★

스토어에 올리기 전 확인

갈래 2·3에서 출시할 때만. 아이콘·스크린샷·개인정보처리방침·서명 키 백업·앱 ID와 버전.

출시 전 확인 목록
막히면

본 그대로(오류 문구까지) AI에게 말합니다. 자주 막히는 곳과 해결은 막혔을 때에 있습니다.

AI 도구는 무엇이든

같은 순서를 Claude Code, 실습실(Claude·Gemini 키), 실습실 예시 모드 어느 것으로도 따라갈 수 있습니다. 갈래 2·3의 데모에는 단계마다 Claude Code로 하는 법이 있습니다.

체크 표시는 이 브라우저에만 저장됩니다. 선생님이 수업 진도를 확인하는 기능은 아닙니다.
